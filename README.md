# Etch-a-Sketch

A browser-based sketch pad built with HTML, CSS, and vanilla JavaScript.
Part of The Odin Project's Foundations course.

## Features

- 16x16 grid by default, created with JavaScript
- Hover over a square to color it with a random RGB color
- Each hover on the same square darkens it by 10% until it's fully solid
- "New Grid" button lets you choose 1-100 squares per side, and the grid stays 800x800px

## How to run

Open `index.html` in your browser.

## What I learned

- Creating and removing DOM elements with JavaScript
- Using Flexbox to lay out a grid
- Handling events with `addEventListener`
